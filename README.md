## 📖 About the Project

**DataSpark** is a comprehensive retail analytics project for Global Electronics. [cite: 1] [cite_start]As part of the data analytics team, the objective is to conduct a thorough Exploratory Data Analysis (EDA) to uncover valuable insights from the company's data. [cite: 3] [cite_start]The project aims to provide actionable recommendations to enhance customer satisfaction, optimize operations, and drive overall business growth. [cite: 4] [cite_start]By leveraging datasets on customers, products, sales, and stores, this analysis helps the company better understand its business and identify key areas for improvement. 

---

## ✨ Key Features

***Customer Analysis:** Analyzes the distribution of customers based on demographics like gender and age.
***Sales Analysis:** Evaluates overall sales performance over time, identifies top-performing products, and assesses the performance of different stores.
***Product Analysis:** Identifies the most popular products and analyzes sales performance across different product categories.
***Store Analysis:** Evaluates store performance based on sales and geographical location to identify high-performing regions.
***Interactive Dashboard:** A dynamic Power BI dashboard allows for an interactive exploration of the data and key findings.

## 🏁 Getting Started

### Prerequisites

* Python 3.x
* Jupyter Notebook
* MySQL Server (e.g., tidbcloud.com)
* Power BI Desktop


### Usage

1.  **Data Cleaning and Preparation:**
    *Open and run the `Retail_Analytics.ipynb` notebook to clean the data and load it into the database.
2.  **Exploratory Data Analysis:**
    *Open and run the `analysis.ipynb` notebook to explore the data and generate visualizations.
3.  **Interactive Dashboard:**
    *Open the `power bi final.pbix` file in Power BI Desktop to interact with the dashboard.
